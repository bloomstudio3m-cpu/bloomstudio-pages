# NOIR COFFEE — Claude Code版（担当：ルカ）

BLOOM LAB｜AI BUILD BATTLE 用の、架空カフェの注文デモWebアプリです。
**この版はClaude Codeが独立して制作しました。** Codex版の成果物と、事前にあったD作成の試作（`claude-code/index.html`）は参照していません。

> デモです。実際の注文・決済・個人情報の送信は一切行いません。外部への通信もありません（テストで確認済み）。

## 起動方法

ビルドは不要です。

- ローカル：`index.html` をブラウザで開くだけで動きます。
- SNS撮影用：`index.html?intro=1` で開くと、静的メニュー表が表示され、「注文アプリを開く」を押すとアプリに切り替わります。`?intro=auto` なら2.8秒後に自動で切り替わります。

## Netlifyでの公開手順（MAIの承認後に実施）

1. Netlifyで「Add new site → Deploy manually」を選びます。
2. このフォルダ（`claude-code-version/`）をドラッグ＆ドロップします。
3. ビルドコマンドは不要です。公開ディレクトリはこのフォルダそのものです。

GitHub連携で公開する場合は、Base directory を `bloom-lab/claude-code-version` にして、Build command は空欄にします。

## 実装した機能

1. トップのビジュアル演出：「NOIR」の文字が下からせり上がり、罫線が伸びて、リード文がフェードインします。下にマーキーも流れます。
2. 商品一覧：6商品（ドリンク3・スイーツ3）。名前・説明・価格はすべて架空です。
3. カテゴリ切替：「すべて／ドリンク／スイーツ」。件数表示つきで、切り替えると商品がアニメーションで並び直します。
4. 商品の選択とカート追加：追加するとボタンが数量ステッパーに変わり、トーストが出て、カート数が弾むように動きます。
5. 数量の変更と削除：商品カード・PCのサイドカート・確認画面のどこからでも操作できます。上限は1商品20個です。
6. 合計金額の自動計算：税込のJPYで表示します（例：¥1,540）。
7. 注文確認画面：スマホでは下から出るシート、PCではモーダルで表示します。DEMOであることを明記しています。
8. デモ完了画面：DEMOスタンプ、控え番号（DEMO-XXXX）、合計、NOIR COFFEEのロゴを表示します。
9. スマホ対応：下部固定の「注文内容を確認」バー、タップ領域44px以上、safe-area対応。
10. アニメーション：ヒーロー、カードの出現、シート、トースト、カウントの弾み、イントロの切替。
11. アクセシビリティ：スキップリンク、セマンティックHTML、`aria-pressed` のフィルター、`aria-live` での読み上げ、再描画後もフォーカスを保持、ダイアログを閉じたら元のボタンへフォーカスが戻ります。
12. アニメーション軽減設定（`prefers-reduced-motion`）：すべての動きを止めて、すぐに表示します。マーキーも止まります。
13. 静的メニュー表（`menu.html`）と、静的メニューからアプリへ変わるイントロ（`?intro=1`）。

## 実装しなかった機能・指示書との差分

- **写真**：外部画像は使っていません。利用条件の確認が必要になることと、実在店舗の素材と誤解されるのを避けるためです。代わりにモノクロのSVGイラストを使っています。実写を入れる場合は、自分で撮影した写真か、商用利用できる素材を `art` 部分に差し替えてください。
- **15秒動画の撮影そのもの**：この版には含めていません。画面側の流れ（静的メニュー → アプリ → 追加 → 完了画面とロゴ）は撮影できる状態にしてあります。
- カートの内容は保存していません。リロードすると消えます（データを残さないための意図的な仕様です）。
- 決済、注文送信、個人情報の入力欄は、要件どおり設けていません。

## SNS撮影の流れ（15秒）

| 秒 | 操作 |
|---|---|
| 0〜3 | `index.html?intro=1` で静的メニュー表を表示 |
| 3〜6 | 「注文アプリを開く」をタップ → メニュー表が消え、NOIRのヒーローがせり上がる |
| 6〜12 | 「メニューを見る」→ 商品を追加 → 数量を＋ → 下部バーの金額が変わる |
| 12〜15 | 「注文内容を確認」→「デモ注文を確定する」→ DEMOスタンプとNOIR COFFEEのロゴ |

## 動作確認結果（2026-11-03・Playwright/Chromium）

`node tests.e2e.js` の結果は **68項目すべて合格** でした（D第1次審査の対応後）。初回の提出時点では32項目でした。

- スマホ390px：横スクロールなし、6商品の表示、ドリンク／スイーツの絞り込み、追加・＋・−、合計（¥1,540 → ¥960）、確認画面、確認画面での削除、デモ完了、カートを空にする、空カートの表示、空のときは確定ボタンが無効、Escで閉じる、数量上限20
- イントロ：表示されること、切り替わってヒーローが表示されること
- PC1440px：横スクロールなし、キーボードでの絞り込み・追加（フォーカスが＋ボタンに残る）、サイドカートの合計と削除、ダイアログを開くとフォーカスが中に入り、閉じると元のボタンに戻る
- reduced-motion：ヒーローがすぐ表示される、マーキーが止まる、イントロがすぐ閉じる
- 静的メニュー：390pxで横スクロールなし
- JSエラー0件、外部へのネットワーク通信0件

- アクセシビリティ：イントロのフォーカス移動、注文完了後の読み上げ、数量変更・削除時のフォーカス維持（詳しくは `REVIEW_01.md`）
- スマホの端末エミュレーション（iPhone SE / iPhone 13 / Pixel 7）：横スクロール、文字のはみ出し、日本語の行頭禁則、下部固定バー、シートの収まり、背景スクロールの固定、注文完了まで

未検証：iOS Safari・Android Chromeの**実機**と、VoiceOver/TalkBackでの読み上げ。この制作環境にはChromiumしかなく、Safari（WebKit）では動かせていません。確認の手順は `REVIEW_01.md` にあります。
