# motion-v6｜FROM CODE TO EXPERIENCE — 15秒絵コンテ

制作：ルカ（Claude Code）／状態：**D審査待ち（本編は未制作）**
仕様：1080×1920（9:16）、15秒、30fps、BGMなし（ヒット点だけ指定）

## 全体のルール

- **画面は3層**（奥から順に）
  - 奥：精密グリッド（45pxピッチ、白6%）
  - 中：作業レイヤー（エディタ・ターミナル・指示書・プレビュー）
  - 手前：キネティックタイポ
  カメラはCSSの3D空間（perspective 820px）を動き、各層の移動量の差で奥行きを出す。
- **色**：黒 #0b0b0b、白 #f4f2ee、アクセントは銀（#b9bdc2、文字は#f4f5f6から#8d9196への縦グラデーション）。発光・グリッチ・ネオンは使わない。
- **文字**：太いサンセリフ（weight 900、字間 −0.04em）。キーワードは1文字ずつマスクで立ち上げる（0.26秒、文字間隔0.045秒）。
- **セーフゾーン**：大事な文字は、1920pxのうち上230px・下420px・右140pxに置かない。Instagramリールの画面UIと重ならないようにするため。
- **事実の扱い**
  - 0〜7秒の作業画面は「制作ログから再現」と常時表示する。
  - コード・指示書・テスト出力・時刻は、実際の記録だけを使う。
  - 最後のキーワードはREADY／COMPLETE（DEPLOYは使わない）。
- **ループ**：最後のフレームが冒頭のコードの壁へ戻るように設計し、リピート再生でつながって見せる。

## 指が止まるためにやること（R・ルカの提案。演出の範囲内でできること）

1. **最初の0.3秒で「AI BUILDS」が画面幅いっぱい**に出る。黒い画面からフェードインで始めない。
2. **7〜9秒の変形は「どの値がどこへ行ったか」を目で追える速さにとどめる**。追えた気持ちよさが保存とシェアにつながる。
3. **ループ**で終わり、2周目に入っても違和感がないようにする（完視聴率・再生回数のため）。
4. 比較投稿の「A／Bどっち派？」は、映像には入れず投稿文と固定コメントで聞く。映像の完成度を落とさないため。
